Проектирую системы, в которых бизнес-процесс становится прозрачным и управляемым: заявки, записи, оплаты, роли, отчётность и клиентские сценарии. Сначала описываю правила и границы, затем собираю рабочие этапы, закрываю критичную логику тестами и довожу систему до запуска.

## Стек, подтверждённый проектами

| Направление | Технологии |
|---|---|
| Backend | Python · FastAPI · NestJS · Express · Pydantic · Uvicorn |
| Frontend | TypeScript · React · Vite · Tailwind CSS · React Router · PWA |
| Данные | PostgreSQL · Redis · SQLAlchemy Async · Alembic · Prisma |
| Интеграции | Telegram / aiogram · Socket.IO · WebSocket · S3 · OpenAI API |
| Процессы и качество | ARQ · APScheduler · Docker Compose · pytest · Vitest · GitHub Actions |

## Как работаю

```text
РАЗБОР ПРОЦЕССА  →  ТЗ И ПРАВИЛА  →  РАБОЧИЕ ЭТАПЫ  →  ЗАПУСК И ПОДДЕРЖКА
```

Критичные правила — пересечения записей, цены, предоплаты, права и денежные операции — проектирую так, чтобы их проверяла сама система, а не память сотрудника.

## Engineering approach

```text
PROCESS DISCOVERY  →  RULES & SPECIFICATION  →  WORKING INCREMENTS  →  TESTS  →  LAUNCH & ITERATION
```

I design critical rules—booking conflicts, pricing, deposits, permissions, and financial operations—so that the system verifies them rather than relying on a team member’s memory. The implementation relies on database constraints, migrations, background jobs, tests, and audit-friendly state changes.

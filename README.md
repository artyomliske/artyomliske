# Артём Лиске

Разрабатываю системы автоматизации бизнес-процессов: CRM, Telegram-боты и личные кабинеты. Беру задачу от разбора процесса и технического задания до запуска на сервере, переноса данных и сопровождения.

**Основной стек:** Python, FastAPI, PostgreSQL, aiogram, TypeScript, React, NestJS, Docker и GitHub Actions.

## Избранная работа

| Проект | Что сделано | Технологии |
|---|---|---|
| [Портфолио и кейсы](https://artyomliske.github.io/) | Шесть систем для контент-студии, покерного клуба, театра, строительства и контент-маркетинга | CRM, Telegram, PWA, PostgreSQL |
| [StudioCRM](https://artyomliske.github.io/#case-studio) | Бронирование, оплаты, производство, финансы и клиентский бот в одном процессе | FastAPI, PostgreSQL, aiogram |
| [Chip House CRM](https://artyomliske.github.io/#case-chcrm) | Турнирная CRM, табло в зале, рассадка, рейтинг и взносы | NestJS, React, PostgreSQL, Socket.IO |
| [Калькулятор смет](https://artyomliske.github.io/#case-estimate) | Внутренний сервис расчёта работ и аналитики смет | TypeScript, React, PostgreSQL |

## Как я работаю

Сначала фиксирую процесс, границы системы и правила расчёта. Затем собираю работающие этапы с приоритетом на ближайшую операционную боль. Критичные правила закрываю тестами, а после запуска остаюсь на связи для развития системы.
